# 新拼接电路代码说明

## 项目功能

本项目是基于 STM32F10x 的电机与舵机控制程序，主要功能如下：

- 通过 PS2 无线手柄读取按键和摇杆数据。
- 使用左摇杆上下方向控制车辆前进、后退速度。
- 使用右摇杆左右方向控制车辆左右转向。
- 控制 4 个 Emm_V5 闭环步进电机驱动器同步运动。
- 通过 TIM8 输出 PWM 控制 3 路舵机。
- 支持急停功能，同时停止电机和舵机。

## 基本控制逻辑

程序上电后会完成板级外设、串口、TIM8 PWM 和 PS2 手柄初始化，并等待约 2 秒。

主循环中会持续扫描 PS2 手柄：

- 按下 `START` 后启用 PS2 控制。
- 左摇杆上下方向控制前进/后退。
- 右摇杆左右方向控制原地或差速转向。
- 同时按下 `L1 + L2` 后，3 路舵机执行正向动作。
- 同时按下 `R1 + R2` 后执行急停，关闭 PS2 控制并停止所有电机和舵机。

## 主要参数

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 摇杆中心值 | `128` | PS2 摇杆中位值 |
| 摇杆死区 | `12` | 小范围摇杆抖动会被忽略 |
| 电机最大速度 | `1000 RPM` | 程序限制的最大目标转速 |
| 电机加速度 | `10` | 发送给 Emm_V5 的加速度参数 |
| 电机地址 | `1, 2, 3, 4` | 4 个电机驱动器地址 |
| 控制周期延时 | `20 ms` | 主循环末尾延时 |
| 电机命令间隔 | `5 ms` | 逐个发送电机命令时的间隔 |

## 外设与引脚

### USART1

用于和 Emm_V5 电机驱动器通信。

| 引脚 | 功能 |
| --- | --- |
| `PA9` | USART1_TX |
| `PA10` | USART1_RX |

串口参数：

- 波特率：`115200`
- 数据位：`8`
- 停止位：`1`
- 校验位：无
- 硬件流控：无

### PS2 手柄接口

| 引脚 | 功能 |
| --- | --- |
| `PA4` | DI |
| `PA5` | CMD |
| `PA6` | CS |
| `PA7` | CLK |

### 舵机 PWM

TIM8 输出 3 路 PWM，连接在 `PC6`、`PC7`、`PC8`。

| 参数 | 数值 |
| --- | --- |
| 定时器 | `TIM8` |
| 周期计数 | `200 - 1` |
| 预分频 | `7200 - 1` |
| 停止脉宽 | `15` |
| 正向脉宽 | `5` |
| 反向脉宽 | `25` |

## 代码结构

| 路径 | 说明 |
| --- | --- |
| `我的电路代码/APP/main.c` | 主程序，包含 PS2 控制逻辑、电机速度计算和急停处理 |
| `我的电路代码/BSP/board.c` | NVIC、时钟、USART1 初始化 |
| `我的电路代码/BSP/Emm_V5.c` | Emm_V5 电机驱动器串口命令封装 |
| `我的电路代码/BSP/server.c` | TIM8 PWM 与舵机控制 |
| `我的电路代码/DRIVERS/ps2.c` | PS2 手柄通信与数据解析 |
| `我的电路代码/DRIVERS/delay.c` | 延时函数 |

## 注意事项

- 使用前需要确认 4 个 Emm_V5 驱动器地址分别设置为 `1`、`2`、`3`、`4`。
- 电机正反方向由 `MOTOR_LEFT_FORWARD_DIR` 和 `MOTOR_RIGHT_FORWARD_DIR` 决定，若实际方向相反，可在 `main.c` 中调整。
- 舵机当前只在 `L1 + L2` 触发时执行正向动作，急停时会统一停止。
- 工程使用 STM32F10x 标准外设库，Keil 工程文件位于 `我的电路代码/PRJ/STM32_UART_CMD.uvprojx`。
